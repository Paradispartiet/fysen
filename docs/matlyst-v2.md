# Matlyst v2 — avløst

Denne produktkontrakten er avløst av [`docs/matlyst-v3.md`](./matlyst-v3.md).

V2 etablerte skillet mellom **Hva frister?** og konkrete kjøkken, production-backed canonical discovery-retter, live-dekningsrangering, lystutforskeren og den filtrerbare **Alle kjøkken**-katalogen.

V3 beholder disse egenskapene og låser en enklere direkte flyt:

**kjøkken → rett → serveringssteder**

Historikken til v2-kontrakten ligger fortsatt i Git.
