# Fysen wordmark

Approved food-free wordmark, 25 November 2026. The SVG is a contour trace of the approved transparent 1133 × 531 PNG, using the original cream (#faf5d2) and green (#08300c) colors. Raster app icons and the native header are rendered from those same contours; no new illustration or font substitution. Earlier brand assets remain in the repository for archival purposes.
